# Day 2: Titanic Descriptive Analysis

## Summary
Explored the cleaned Titanic dataset through descriptive counts and survival breakdowns across class, gender, and age groups.

## Key Findings
- 418 total passengers, 152 survived (36%), 266 deceased
- 1st class: 107 | 2nd class: 93 | 3rd class: 218
- 266 male vs 152 female passengers
- 327 passengers had no recorded Cabin (78% missing)
- Survival rates were highest among 1st class and female passengers
